¿Qué son los Microservicios?

Según IBM y AWS, los microservicios son un enfoque arquitectónico donde una aplicación se divide en servicios pequeños, independientes y especializados. Cada servicio se encarga de una sola función (ej. el carrito de compras, el login o la generación de facturas) y se comunica con los demás mediante APIs. Esto permite que cada pieza use el lenguaje de programación que mejor le convenga.

A diferencia de la arquitectura monolítica — donde toda la funcionalidad reside en una sola unidad — los microservicios permiten a los equipos desarrollar, desplegar y escalar cada componente de manera independiente.

Ventajas

  • Despliegue independiente por servicio
  • Escalado granular — solo lo que necesitas
  • Equipos pequeños y autónomos (Conway's Law)
  • Tolerancia a fallos — un fallo no tumba todo
  • Flexibilidad tecnológica por servicio
  • Ciclos de desarrollo más rápidos

Desafíos

  • Complejidad de la red y latencia
  • Consistencia de datos distribuidos
  • Depuración y trazabilidad distribuida
  • Gestión de versiones entre servicios
  • Mayor infraestructura requerida
  • Curva de aprendizaje inicial elevada

Docker

Docker es una plataforma que permite empaquetar aplicaciones y sus dependencias en contenedores ligeros, facilitando el despliegue y la gestión de microservicios.
Para que un microservicio funcione igual en tu laptop que en la nube, usamos Contenedores. Como menciona Intel, la "contenedorización" empaqueta el código junto con sus dependencias.

Kubernetes

Kubernetes es una plataforma de orquestación de contenedores que automatiza el despliegue, escalado y gestión de aplicaciones en contenedores.
Permite gestionar clústeres de máquinas virtuales o físicas para ejecutar y escalar aplicaciones distribuidas.

La union con las API's

En una arquitectura de microservicios, el sistema no puede hablar con 50 servicios distintos a la vez. Se usa un API Gateway. Este actúa como un recepcionista único: recibe todas las peticiones, las autentica y las redirige al microservicio correcto.
Es la capa esencial de seguridad y orden en el sistema.
