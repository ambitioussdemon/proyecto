Manejo de Contenedores

Empaqueta, distribuye y ejecuta aplicaciones con total portabilidad. Docker y Kubernetes son las tecnologías que revolucionaron el despliegue moderno.

Las palabras clave del tema son:

Docker Kubernetes Docker Compose

¿Qué es un Contenedor?

Un contenedor es una unidad de software que empaqueta el código de una aplicación junto con todas sus dependencias (librerías, configuración, runtime) en una imagen portable. Esto garantiza que la aplicación se ejecute de manera idéntica en cualquier entorno: desarrollo local, staging o producción.

A diferencia de las máquinas virtuales, los contenedores comparten el kernel del sistema operativo anfitrión, lo que los hace mucho más ligeros y rápidos para iniciar (<1 segundo vs. minutos).

Docker — Fundamentos

  • Dockerfile — Script con instrucciones para construir la imagen
  • Image — Plantilla inmutable del contenedor
  • Container — Instancia en ejecución de una imagen
  • Registry — Repositorio de imágenes (Docker Hub, ECR)
  • Volume — Almacenamiento persistente
  • Network — Comunicación entre contenedores

Kubernetes — Orquestación

  • Pod — Unidad mínima de despliegue (1+ contenedores)
  • Deployment — Gestiona réplicas de pods
  • Service — Exposición y balanceo de carga
  • Ingress — Enrutamiento HTTP externo
  • ConfigMap / Secret — Configuración externalizada
  • HPA — Auto-escalado horizontal
