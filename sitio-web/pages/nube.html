¿Qué es Cloud Computing?

Cloud computing es el acceso bajo demanda a recursos de cómputo — servidores, almacenamiento, bases de datos, redes, software — a través de internet con un modelo de pago por uso. Elimina la necesidad de poseer infraestructura física y permite escalar en segundos.

Existen tres modelos de servicio principales: IaaS (Infrastructure as a Service), PaaS (Platform as a Service) y SaaS (Software as a Service). Y tres modelos de despliegue: nube pública, privada e híbrida.

Arquitectura Serverless

En serverless, el desarrollador escribe funciones (FaaS) y el proveedor gestiona automáticamente la infraestructura, el escalado y la disponibilidad.

  • Sin gestión de servidores
  • Pago solo por ejecución real (milisegundos)
  • Escalado automático a cero
  • Ejemplos: AWS Lambda, Azure Functions, Cloud Run
  • Ideal para eventos, webhooks y tareas programadas

Infraestructura como Código (IaC)

Definir y gestionar toda la infraestructura mediante archivos de configuración versionados. Beneficios:

  • Terraform — Multi-cloud, HCL declarativo
  • AWS CloudFormation — Nativo de AWS en YAML/JSON
  • Ansible — Automatización y configuración
  • Pulumi — IaC con lenguajes de programación reales
